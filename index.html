🎤 무선마이크 찾기 탐지음 없음 · v2

강의장 마이크라면 먼저 확인하세요

일반 UHF/VHF 무선마이크는 폰의 블루투스 검색으로 찾을 수 없습니다. 이 페이지도 폰만으로 해당 전파나 위치를 측정할 수 없습니다.

  1. 담당자에게 해당 마이크의 믹서 채널을 뮤트해 달라고 하세요. 수신기 전원은 켜 둡니다.
  2. 수신기의 RF/안테나 표시로 송신 신호 수신 여부를 확인하세요. 신호가 있어도 위치가 확정되지는 않습니다.
  3. 휴대 가능한 수신기는 전원과 안테나를 유지한 채 이동하며 RF 표시를 비교할 수 있습니다. 고정 수신기라면 장비를 임의로 분리하지 말고 담당자 도움을 받으세요.

송신기 전원이 꺼졌거나 배터리가 없으면 실시간 전파 탐색은 불가능합니다. 수신기 RF 표시 설명 (Shure 예시)

이 페이지는 소리를 재생하지 않습니다.
단, 실제 강의장 스피커 연결은 웹에서 제어할 수 없습니다. 폰을 연결하기 전에 담당자에게 해당 믹서 채널의 메인·보조·모니터 출력을 뮤트해 달라고 하세요. 초음파도 무소음이 보장되지 않아 재생 기능을 제거했습니다.
수신기 입력인지 확인되지 않았습니다. 내장 마이크일 수 있어요. 외부 수신기를 연결하고 입력 장치 이름을 확인하세요.
입력 레벨– dB

수신기의 별도 출력을 폰에서 지원하는 USB 오디오 인터페이스 또는 적절한 입력 어댑터로 연결해야 합니다. 일반 충전 케이블이나 출력 전용 젠더로는 입력되지 않습니다.
숫자는 입력 소리 크기이며 거리·RF 세기가 아닙니다. 폰의 내장 마이크가 선택됐다면 잃어버린 송신기의 소리가 아닙니다. 입력이 커져도 가까워졌다고 판단할 수 없습니다. 이 모드에서는 진동하지 않습니다.

블루투스 기능이 있는 송신기(예: 일부 DJI/Rode 제품)만 찾을 수 있어요. 일반 강의장 UHF/VHF 무선마이크는 이 검색으로 찾을 수 없습니다. 블루투스 광고를 실제로 내보내는 송신기만 대상입니다. 안드로이드 Chrome 전용.
